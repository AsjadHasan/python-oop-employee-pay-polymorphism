# python-oop-employee-pay-polymorphism
A Python OOP exercise demonstrating inheritance, method overriding, and polymorphism through full-time and part-time employee pay calculations.
<br>
Topics Covered:
<br>

1. Object-Oriented Programming (OOP) – Classes and objects.
2. Inheritance – Sharing common attributes through the Employee base class.
3. Method Overriding – Implementing different calculate_pay() methods.
4. Polymorphism – Using the same method name for different salary calculations.
5. super() Function – Calling the parent class constructor.
6. __init__() Constructor – Initializing employee attributes.
7. Business Logic – Calculating monthly salary and hourly wages.
